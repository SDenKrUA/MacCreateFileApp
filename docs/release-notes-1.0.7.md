# Mac Create File 1.0.7

This release simplifies the default Finder submenu and adds an optional developer mode.

## What Changed

- The default `Create File` submenu now shows only:
  - Text File
  - PDF Document
  - Word Document
  - Excel Workbook
  - PowerPoint Presentation
- Added `Show developer file types` in the main app.
- Developer file types include Markdown, RTF, CSV, JSON, HTML, CSS, JavaScript, Python, Swift, and Shell Script.
- The setting is stored in `~/Library/Application Support/MacCreateFileApp/Settings.plist`.

## Install

1. Download `MacCreateFile-1.0.7-mac-arm64.zip`.
2. Unzip it.
3. Move `Mac Create File.app` to `Applications`.
4. Open the app and click `Enable Finder Extension`.

Use the toggle in the app when you want the full developer file type list.
