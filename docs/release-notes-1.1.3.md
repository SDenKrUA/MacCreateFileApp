# Mac Create File 1.1.3

## Added

- Added a localized `Show in Dock` switch to the main app.
- The setting is remembered between launches.

## Changed

- When `Show in Dock` is off, the app uses macOS accessory activation policy so it stays hidden from the Dock while its window can still be opened from Applications, Finder, or Spotlight.
- The release artifact remains a `.dmg` installer image: `MacCreateFile-1.1.3-mac-arm64.dmg`.
