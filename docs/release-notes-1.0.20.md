# Mac Create File 1.0.20

## Changed

- Redrew the `Create File` and `Copy Path` Finder menu document icons after visual review.
- Made document folded corners larger and lighter so they look closer to native Finder glyphs.
- Changed `Copy Path` to show a front document with only a partial rear document hint.

## Fixed

- Added explicit Finder Sync monitored roots for Desktop, Documents, iCloud Drive, Mobile Documents, CloudStorage, and installed CloudStorage provider folders such as OneDrive.
- Added startup logging of monitored Finder roots for easier cloud-folder debugging.
