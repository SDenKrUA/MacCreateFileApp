# Mac Create File 1.0.16

## Fixed

- PowerPoint files are now created from a real blank `.pptx` template, improving compatibility with Keynote and PowerPoint.
- Word, Excel, and PDF files are also created from bundled blank templates instead of minimal generated data.

## Changed

- Removed the old minimal OOXML/PDF generator.
- Added bundled templates under `ExtensionResources/Templates`.
