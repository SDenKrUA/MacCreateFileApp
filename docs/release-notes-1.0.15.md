# Mac Create File 1.0.15

## Added

- `Uninstall Completely` button in the main app.
- Confirmation dialog before cleanup.
- Localized uninstall status messages.

## Behavior

- Disables the Finder extension.
- Restarts Finder.
- Removes support files, logs, legacy App Group leftovers, and the extension container where macOS allows it.
- Leaves `Mac Create File.app` in place so the user can move it to Trash manually.
