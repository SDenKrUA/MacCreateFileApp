# Mac Create File 1.0.0

Initial release.

Mac Create File adds a Finder right-click menu for creating new files in the current folder. It supports English and Ukrainian and includes common document, web, script, and Office-style file types.

## Install

1. Download the `.dmg`.
2. Drag `Mac Create File.app` to `Applications`.
3. Open the app.
4. Enable the Finder extension.
5. Right-click in Finder and choose `Create File`.

If macOS blocks the app because it is not notarized, right-click the app and choose `Open`, then confirm the launch.
