# Mac Create File 1.0.6

This release removes the oversized blank space that Finder showed after the `Create File` menu item.

## What Changed

- Removed the separator between `Create File` and `Copy Path`.

## Install

1. Download `MacCreateFile-1.0.6-mac-arm64.zip`.
2. Unzip it.
3. Move `Mac Create File.app` to `Applications`.
4. Open the app and click `Enable Finder Extension`.
